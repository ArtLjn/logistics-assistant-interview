# 公开验收用例

| 问题 | 验收标准 |
| --- | --- |
| 盘点时发现账面数比实物多，我要记哪些信息 | 检索前三含 `INV-01`，引用该条并说明要记录的字段 |
| HD202611002 现在是什么状态 | 只调用订单工具，返回“待审核” |
| HD202611001 怎么还没发出去，能确定卡在哪吗 | 先查订单，返回“已审核待出库”，引用 `OUT-02` 给出排查项，说明原因待核实 |
| HD202699999 这票的状态是什么 | 返回 `order_not_found` |
| 跨境冷链的破损赔付上限是多少 | 返回 `insufficient_evidence`，说明缺少赔付规则 |

另请自检输入校验、调用顺序、重复请求一致性，以及引用是否为 SOP 连续原文。合并 `main` 后复测新增订单、新条款和至少一条原有用例。
